# FutureDrive — Automotive Concept Website

A responsive front-end automotive concept website built with HTML, CSS, and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open the `FutureDrive` folder.
3. Double-click `index.html` to open it in Chrome.
4. No Live Server, installation, or backend is required.

## Features
- Futuristic dark-purple automotive design.
- Hero section and vehicle collection.
- Five concept vehicles: Aether X, Vanta R, Nova S, Zenith E, and Orion GT.
- Technology and performance content sections.
- Responsive navigation and layout.
- CSS reveal and hover effects.

## Project scope
This is a static front-end prototype. Vehicle names and specifications are fictional concept data. It does not include a backend, database, authentication, or payment processing.
